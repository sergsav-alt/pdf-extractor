УСТАВ НАУЧНО-ТЕХНИЧЕСКОГО ПРОЕКТА
Наименование проекта
Исследование трансформации смысловых конструкций в исторических печатных материалах на основе цифровой обработки архивных скан-копий и семантического анализа текстового содержания.

1. Основание для запуска проекта
В распоряжении исследовательской группы находятся архивные документы в виде PDF-скан-копий, полученных из фондов Библиотеки Конгресса СAСШ. Документы преимущественно выполнены на английском языке и представляют собой материалы различных временных эпох.

2. Цель проекта
Создание научно-технического комплекса обработки архивных документов, обеспечивающего:
	•	восстановление и цифровую очистку исходных скан-копий;
	•	преобразование документов в структурированный текстовый формат;
	•	обеспечение возможности перевода на русский язык;

3. Основные задачи проекта
OCR-преобразование
Необходимо обеспечить:
	•	извлечение текста из PDF-сканов;
	•	преобразование результатов в формат DOC/DOCX;
	•	сохранение структуры документа;


4. Ожидаемые результаты
По итогам проекта предполагается получить:
	•	Цифровой архив очищенных документов.
	•	Набор DOC/DOCX-файлов с распознанным текстом.
